## 实际实现

| 模块 | 已实现行为 |
|---|---|
| Source / geometry | 固定 Project revision、build ID、工程引擎版本及文件哈希；使用该 build 的 STEP、resolved design 和加工记录，不重新布路。OCCT 精确隐藏线投影，矢量曲线离散精度为模型空间 0.002 mm |
| Drawing 文档 | `schema_version=1`；工程源快照、生成几何与可编辑表现分开；独立乐观锁；项目内多文档、保存历史、复制、归档只读及受控删除 |
| Customer | 六面/等轴测、外形尺寸、源端口/孔腔标识、端口表、材料、原理图、PMC 标题栏与说明 |
| Manufacturing | 六面基准坐标、去重坐标尺寸、隐藏线、直剖及精确截面填充、多页加工表；阶梯/锥形/环形/偏置加工、旋转角、斜孔轴线、已知刀具与加工说明均引用固定源 |
| 编辑 | 纸上选择与拖动、尺寸增删及精度/位置、说明/文字/引出线/标签、视图位置/比例/可见性、隐藏线/中心线、表格/备注/分页、标题栏、纸张及页序、缩放平移、撤销重做 |
| 模板 | PMC 客户/制造两种默认模板；可保存、复用表现模板；不复制旧产品身份、旧图号、源附件或特征备注 |
| 关联更新 | 源变化标识；先生成可取消预览再应用；保留视图位置/比例、有效标注偏移、独立文字及抑制记录；删除/换面/替换/操作身份变化明确标为失效，可重新关联或删除 |
| 生命周期 | Draft、修订/保存历史、Released；旧发行 PDF 原字节保留、哈希核验；新修订可编辑；工程例外随发行记录及 PDF 可见 |
| PDF | 真实纸张尺寸、共享屏幕/PDF 布局、嵌入字体、工程矢量、多页；原 PDF 原理图保留矢量，删除其活动注释；PMC 公司标志使用有来源的打印分辨率图片 |
| 最小工程扩展 | 普通盲孔/贯穿安装孔进入现有 Feature / BRep；不成为液压节点。贯穿深度、外壁、安装孔/油路相交、实体完整性继续校验；旧字段序列化兼容 |

Library 和 Manifold 仍是工程事实源。图纸不补造供应商孔腔、螺纹、兼容性、堵头座或刀具数据；未确认产品身份显示待复核。尺寸数值由关联源计算，禁止用输入文字覆盖数值。

## 密集基准实测

本机 Windows / Python 3.11 / CadQuery 2.7 / OCP 7.8.1；进程可见 16 个逻辑处理器。硬件型号和物理内存的 WMI 查询被本机权限阻止，未猜测数值。

模型为六面共 120 个明确普通盲孔，420×360×160 mm，工程 PASS。最初 CAD 构建约 178.807 s，属于源建模步骤。复用同一 build 的最终图纸生成 **2.364 s**、PDF **1.369 s**；15 页、318 条标注、694,898 字节。这是本机单次实测，不是通用性能保证。

总图、面坐标页、内部剖面及续表完成渲染审阅。浏览器实际验证选中 H1、移动其引出线偏移、撤销/重做、缩放、保存和重开；编辑不重算 CAD。输出：`dense-manufacturing.pdf`、`dense-final-*.png`、`dense-editor-final.png`。
